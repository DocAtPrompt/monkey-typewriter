monkey-typewriter

A character-level Markov chain text generator running entirely in your browser. Set an order n, a temperature, choose character or word n-grams, and the page will build the table and produce text in the style of whatever you paste in.

Source on GitHub · Borel 1913 → Shannon 1948 → Travesty 1984 → today
